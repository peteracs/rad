# Frankl search dogfood

This project attacks Frankl's union-closed sets conjecture at the first open
ground-set size, `N=13`, while keeping exhaustive results, heuristic results,
and certificates sharply separated.

## Pipeline

- `exhaustive_n4.rad` checks all 65,536 labeled families on four elements.
- `search.rad` uses native Boolean-lattice closure/statistics kernels,
  family-distinct beam search, deterministic mutation batches,
  `simulate_many`, COW forks, seeds, digests, Causal Laws, Candidate
  Constraints, `why()`, and record/replay.
- `cyclic_universes.rad` exhausts all 198,765 closures generated by one or two
  cyclic rotation orbits, combines eight forked enumeration lanes through a
  causal settlement, and makes the complement/deletion obstruction explicit.
- `structure_lib.rad` contains reusable rotation, complement, rank, and
  dual-majority mathematics rather than inflating either executable.
- `verify_certificate.py` independently regenerates the family and uses exact
  OR zeta/Möbius convolution to audit all pairwise unions in `O(n 2^n)`.
- `test_verify_certificate.py` proves malformed mathematical claims are
  rejected, including when Python assertions are optimized away.
- `verify_structure.py` independently verifies the structural certificate and,
  unless passed `--quick`, reproduces the full cyclic enumeration.

The default release run evaluates 258,561 exact generator closures and retains
only compact candidate summaries in speculative worlds. It materializes the
complete best family and the closest strict positive near-miss only after the
search. The latter is `2049/4097`, margin `+1`, with dual minimum surplus `-1`.

```powershell
projects/dogfood/frankl-search/run.ps1
```

Quick smoke:

```powershell
target/release/rad.exe projects/dogfood/frankl-search/search.rad `
  --experimental-laws -- 1 4 2 1 24 quick
```

Arguments are:

```text
generations children_per_parent beam_width local_trials generator_slots [quick]
```

`quick` skips only the project extension's final `lattice_is_closed()` audit. The independent
checker still proves closure from the emitted certificate.

## Scope

The 24/32/48-slot campaign evaluated 3,102,723 exact closures in 51.94 seconds
on the development workstation. It found no negative Frankl margin. This is a
real witness search, not an exhaustive proof for `N=13`: the space of all
families has size `2^8192`.

Outputs are written under `out/` and ignored by Git.

## Structural result

For a deleted family `D = P([13]) - F`, a Frankl counterexample needs every
element in strictly more than half of `D`, while union closure requires `D` to
hit every decomposition of every deleted union. The high-rank deletion has
the desired element-majority surplus `923`, but leaves `15,147,132` ordered
union violations. Closure repair returns `P([13])` and margin zero.

In the exact cyclic class, all 630 equality cases are the same full powerset:
the singleton rotation orbit paired with any orbit. Every other one/two-orbit
closure—198,135 cases—has positive margin; none is negative. This proves the
negative result only for that explicitly enumerated class, not for all
union-closed families.
