# Remove the excess-length requirement from the arithmetic matrix route

No web search was used. The cotorsion, ordinary control and localization
statements are used as supplied mathematical premises from the user's message;
this program does not verify those background theorems.

Write R=Q_p[[T]], let X be the supplied finite-length arithmetic R-module,
and let P(T) be a square n-by-n presentation. The supplied control gives

    (X/TX)^* = S_p,   dim S_p=s_p.

## The exact minor criterion

The correct rank target is

    Fitt_m(X)=R,

where Fitt_m is generated by the (n-m)-by-(n-m) minors of P, with the
convention Fitt_m=R if m>=n. Equivalently, at least one of these minors
has a nonzero constant term.

Proof: reduction modulo T identifies coker P(0) with X/TX. Therefore

    s_p = n-rank P(0).

Over Q_p, rank P(0)>=n-m if and only if some (n-m)-minor is nonzero.
That minor lifts to a unit of R. Since R is local with maximal ideal (T),
the minors generate R if and only if one is a unit. Thus

    s_p<=m  <=>  Fitt_m(X)=R.

This is independent of presentation and of the positive Smith block lengths.
It requires no nondegeneracy of the first derived map. The remaining
universal arithmetic statement is that such a unit minor exists at an
eligible prime when the complex analytic rank is m. This statement is
exactly the X3 comparison; it is not proved by computing the criterion.

## An arithmetic quotient with determinant order exactly s_p

There is also a canonical way to replace the stronger determinant target.
Define Y=X/TX, regarded as an R-module with T acting by zero. It is an
arithmetic quotient of the supplied module, and

    Y ~= (R/(T))^s_p.

Any square presentation Q(T) of Y has

    ord_T det Q(T)=length_R(Y)=s_p.

Dualizing its special-value cokernel gives

    ker Q(0)^transpose ~= (Y/TY)^* ~= (X/TX)^* ~= S_p.

Thus the quotient supplies a mathematical existence construction of an
arithmetic matrix whose kernel dimension and determinant order BOTH equal
s_p. A basis gives the elementary presentation Q=T I_(s_p); this is not
an algorithm for determining s_p from the input curve.

This does not imply the original module X has only length-one blocks.
Replacing X by Y changes the module unless TX=0. In particular, an
analytic or characteristic-element comparison for X does not automatically
become a comparison for Y. Proving ord det Q<=m is now exactly X3, not the
stronger original length bound, but is still unproved.

The first derived map for T I_(s_p) is the identity in those coordinates.
That does not prove nondegeneracy of an arithmetic height pairing associated
with the original deformation; it refers to a different module presentation.

## Determinants alone cannot supply the corrected invariant

The following four-by-four presentations all have determinant T^4:

    diag(1,1,T,T^3),     diag(T,T,T,T),     diag(1,1,1,T^4).

Their special-value coranks are respectively 2,4,1. At m=2, their rank
bounds are respectively true,false,true, while their determinant-order
bounds are all false. Even the same exact determinant, not just its order,
therefore does not determine which rank certificate holds. These are
algebraic module examples, not asserted elliptic-curve realizations.

For the first presentation, the top-left two-by-two minor is 1. Its second
Fitting ideal is R despite its determinant having order 4. The quotient Y
has exponents [0,0,1,1] and determinant order 2, but is NOT the same module.
RAD's resolver rejects a forged claim that flattening preserves the module.

## RAD construction and checks

fitting_rank_target.rad constructs diagonal module presentations from
explicit Smith exponents, enumerates their diagonal minors to find the
minimum valuation, and emits actual unit-minor indices when present. Zero
exponents denote unit presentation blocks; only positive exponents count
toward the Selmer dimension. These are synthetic presentations, not computed
Iwasawa modules of individual curves.

It checks 1,250 resource-bound forks, preserves the parent, and settles three
same-determinant diagnostics through WHY. It separately records dimension,
length, quotient length, module preservation, and whether any complex
analytic comparison was proved. The latter remains false in every run.

Run:

    python projects/dogfood/bsd-x/verify_fitting_rank.py

The verifier checks the minor result independently by sorted invariant
factors, validates all emitted unit minors, checks deterministic execution
and replay, and rejects forged analytic comparison and module equivalence.

## What is and is not resolved

Resolved: the matrix target can be stated exactly at the level of Selmer
dimension, using unit minors or the canonical quotient, without requiring
the original deformation to have length-one blocks. The proofs above hold
for arbitrary finite-length R-modules, not just the sampled presentations.

Unresolved: no arithmetic argument from the complex L-function to that
unit-minor condition has been proved. No X1, X3, X5 or X6 is filled. Nothing
here recovers integral p-primary data or analytic normalizations needed
for X6 from the rationalized module.
